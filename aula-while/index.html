Estruturas de Repetição - WHILE

Conteúdo

A estrutura de repetição WHILE é utilizada para executar um bloco de código várias vezes enquanto uma condição permanecer verdadeira.

Antes de cada repetição, o JavaScript verifica a condição. Se ela for verdadeira, o bloco será executado novamente.


"ENQUANTO a condição for verdadeira, execute o código."

Sintaxe:

while (condicao) {
    // código que será repetido
}

Exemplo:

let contador = 1

while (contador <= 5) {
    console.log(contador)
    contador++
}

Neste exemplo, os números de 1 a 5 serão exibidos no console.

Fluxo de Execução

O funcionamento do WHILE segue os seguintes passos:

  • Verifica a condição.
  • Se for verdadeira, executa o bloco de código.
  • Retorna para a condição.
  • Repete o processo até a condição ser falsa.

Cuidado com Loops Infinitos

Um erro comum ao utilizar o WHILE é esquecer de alterar a variável de controle.

Isso faz com que a condição nunca se torne falsa, criando um loop infinito. 

let contador = 1

while (contador <= 5) {
    console.log(contador)
}

Neste exemplo, o valor de contador nunca é alterado, então o loop nunca termina.

Exemplo Prático

let senha = ""

while (senha !== "1234") {
    senha = prompt("Digite a senha:")
}

alert("Acesso liberado!")

O programa continuará solicitando a senha até que o usuário digite o valor correto.
