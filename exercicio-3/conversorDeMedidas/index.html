Conversor de medidas

Conteúdo

Exercício de fixação do curso de Javascript com o objetivo de práticar e criar um conversor de medidas. O programa deverá pedir por um valor em metros e então dar a opção de escolher para qual unidade de medida esse valor deve ser convertido.

As opções são:

  • milímetro (mm)
  • centímetro (cm)
  • decímetro (dm)
  • decâmetro (dam)
  • hectômetro (hm)
  • quilômetro (km)

Como testar?

Basta iniciar a página HTML para ver o funcionamento do código em JS.
