Estruturas Condicionais - SWITCH

Conteúdo

A estrutura condicional SWITCH é utilizada quando precisamos comparar uma mesma variável com diferentes valores possíveis.

Ela pode tornar o código mais organizado e legível quando existem várias condições relacionadas ao mesmo valor.


"SE o valor for X faça uma coisa, SE for Y faça outra, SE for Z faça outra..."

Sintaxe:

switch (variavel) {
    case valor1:
        // código a ser executado
        break;

    case valor2:
        // código a ser executado
        break;

    case valor3:
        // código a ser executado
        break;

    default:
        // código executado caso nenhum valor corresponda
}

Exemplo:

const opcao = "Ataque"

switch (opcao) {
    case "Ataque":
        console.log("Você escolheu atacar!")
        break

    case "Defesa":
        console.log("Você escolheu defender!")
        break

    case "Fugir":
        console.log("Você fugiu da batalha!")
        break

    default:
        console.log("Opção inválida!")
}

Importância do BREAK

O comando break encerra a execução do SWITCH.

Sem ele, o JavaScript continuará executando os próximos cases, mesmo que uma condição já tenha sido satisfeita.

DEFAULT

O bloco default funciona de forma semelhante ao else de uma estrutura IF/ELSE.

Ele será executado quando nenhum dos casos definidos for atendido.
